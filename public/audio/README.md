# Jotty Audio Files

Place the following audio files in this directory for the music player:

1. `ocean-waves.mp3` - Soothing ocean wave sounds
2. `forest-ambience.mp3` - Forest sounds with birds and rustling leaves
3. `gentle-rain.mp3` - Gentle rainfall sounds
4. `meditation-bells.mp3` - Meditation bells and chimes

You can find royalty-free ambient sounds at:

- [Pixabay](https://pixabay.com/sound-effects/)
- [Freesound](https://freesound.org/)
- [Zapsplat](https://www.zapsplat.com/)
