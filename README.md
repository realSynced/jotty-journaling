# Jotty

## Welcome to Jotty

Jotty is a platform that provides you with daily journaling prompts, allows you to schedule journaling sessions, provides you with quotes, and a community where you can post about your journals!

Journaling is a great way to clear your mental space and help you relax, and through Jotty you'll be able to do just that.

## Features

- 📝 Daily journaling prompts
- 🗓️ Schedule journaling sessions
- 💭 Inspirational quotes
- 👥 Community sharing
- 🧠 Mental clarity and relaxation

## Tech Stack

- Next.js 15
- React 19
- Tailwind CSS 4
- Supabase
- Railway
- TypeScript

## Getting Started

```bash
# Install dependencies
npm install

# Run development server with Turbopack
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
